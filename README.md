# MPI + OpenMP + CUDA решатель уравнения Пуассона

Решение уравнения Пуассона с граничными условиями Дирихле методом предобусловленного сопряжённого градиента (PCG) с использованием OpenMP, MPI и CUDA.

## Компиляция и запуск

1. Локальная сборка и тестирование
Скрипт run.sh:
- автоматически компилирует все исходные коды с поддержкой OpenMP, MPI и CUDA;
- запускает последовательную / OpenMP-версию, MPI-версию и (при наличии GPU) MPI+CUDA-версию;
- сохраняет численные решения в директорию solution/;
- записывает профиль работы и консольный вывод в run.log и подкаталоги log/stage_*.


2. Запуск на суперкомпьютере IBM Polus
Скрипт run_polus.sh:
- автоматически настраивает окружение (загружает нужные модули MPI, компилятор, CUDA);
- компилирует код с поддержкой OpenMP/MPI/CUDA под архитектуру GPU кластера;
- создаёт и отправляет задания в систему управления очередью Polus (включая GPU-задачи через config/stage_9/*.lsf);
- собирает результаты вычислений и сохраняет их в solution/ и log/stage_9/;
- пишет журнал выполнения в run_polus.log.

Таким образом, не требуется ручная настройка окружения или ввод множества команд — весь процесс сборки, запуска и сбора результатов автоматизирован.


## Описание программы

Реализация включает несколько режимов вычислений:
	1.	Последовательный / OpenMP режим
- исполняемый файл: task.cpp;
- базовый PCG-решатель, использующий OpenMP-директивы для распараллеливания внутренних циклов при установке переменной окружения OMP_NUM_THREADS.
	2.	MPI-параллельный режим (CPU)
- исполняемый файл: task_mpi.cpp;
- распределение глобальной сетки по MPI-процессам, блочная декомпозиция области, halo-обмен между соседями, глобальные редукции через MPI_Allreduce. Внутри каждого процесса могут использоваться OpenMP-директивы.
	3.	Гибридный режим MPI+OpenMP+CUDA (MPI+CUDA)
- исполняемый файл: task_mpi_cuda.cpp;
- та же MPI-декомпозиция области, но основная работа (оператор Лапласа, векторные обновления, предобработка для редукций) переносится на GPU через класс MPICudaPoissonSolver;
- редукции реализованы в три этапа: предредукция на GPU, локальная редукция на CPU и глобальная редукция в MPI.

Дополнительно реализовано:
- визуализация решений (2D и 3D) в каталоге plot/;
- автоматическое разбиение области на поддомены с сохранением геометрических пропорций (класс DomainDecomposer);
- сбор и слияние результатов от всех MPI-процессов и сохранение глобального решения в формате CSV.


## Выходные данные
- Численные решения для различных размеров сетки находятся в каталоге solution/ (формат CSV).
- Визуализации в каталоге plot/ демонстрируют распределение потенциала в 2D и 3D.
- В debug.log фиксируется поведение невязки (остатка) по итерациям метода PCG для контроля сходимости.
- В operator_analysis/ собраны таблицы и профили, используемые в отчёте для анализа производительности отдельных операторов (Лаплас, обновления, редукции) в режимах CPU / MPI / CUDA.


## Примечания
- Код совместим с компиляторами g++, mpicxx и nvcc, требует поддержки OpenMP, MPI и (для MPI+CUDA) CUDA с соответствующей архитектурой GPU (на Polus — sm_35 / sm_60).
- В качестве тестовой задачи решается уравнение Пуассона с правой частью f(x, y) = 1 на трапециевидной области, аппроксимированной методом фиктивных областей.
- Система легко масштабируется и адаптируется под произвольное количество процессов, нитей и доступных GPU, а также под разные размеры сетки.
